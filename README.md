# Nomes no Extrato — versões

Este repositório guarda só os arquivos de instalação e de atualização do
**Nomes no Extrato**. O código-fonte é privado.

## Instalar

1. Baixe o `NomesNoExtrato-windows-x64.zip` da
   [versão mais recente](https://github.com/Asuurazzz/nomes-no-extrato-releases/releases/latest).
2. Extraia a pasta inteira e abra o `NomesNoExtrato.exe`.

Depois disso o programa avisa quando houver versão nova e se atualiza sozinho.
Cada atualização é assinada digitalmente e conferida pelo programa antes de ser
instalada.
